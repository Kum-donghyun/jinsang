                                    내 안의<br/>진상 고객<br/>유형 테스트
                                </h1>
                                <div className="pixel-box mb-8 mx-4 bg-gray-900">
                                    <p className="text-sm leading-loose">
                                        "어이 알바생! 내가 누군지 알아?"<br/>
                                        야생의 진상 몬스터가 나타났다!<br/>
                                        당신이 만약 분노의 진상이 된다면<br/>
                                        어떤 보스로 군림하게 될까?
                                    </p>
                                </div>
                                <div className="space-y-4 w-full px-4">
                                    <button 
                                        onClick={handleStart}
                                        className="btn-pixel w-full py-4 text-xl blink-text bg-red-600 border-white hover:bg-white hover:text-red-600"
                                    >
                                        &gt; PRESS START &lt;
                                    </button>
                                    <p className="text-gray-400 text-sm">소리, 환불, 규정... 당신의 무기는?</p>
                                </div>
                            </div>
                        )}

                        {/* 퀴즈 화면 */}
                        {step === 'quiz' && (
                            <div className="w-full space-y-6">
                                <div className="flex justify-between items-center mb-2">
                                    <span className="text-yellow-400">STAGE {currentQ + 1} / 12</span>
                                    <span className="text-xs text-gray-400">HP</span>
                                </div>
                                <div className="hp-bar-container mb-8">
                                    <div 
                                        className="hp-bar-fill" 
                                        style={{ width: `${((currentQ) / 12) * 100}%` }}
                                    ></div>
                                </div>

                                <div className="pixel-box min-h-[150px] flex items-center justify-center mb-8">
                                    <p className="text-lg text-center leading-relaxed">
                                        {questions[currentQ].text}
                                    </p>
                                </div>

                                <div className="space-y-4">
                                    {questions[currentQ].options.map((opt, idx) => (
                                        <button 
                                            key={idx}
                                            onClick={() => handleAnswer(opt.type)}
                                            className="btn-pixel w-full py-4 px-4 text-left text-sm leading-relaxed"
                                        >
                                            {'>'} {opt.text}
                                        </button>
                                    ))}
                                </div>
                            </div>
                        )}

                        {/* 로딩 화면 */}
                        {step === 'loading' && (
                            <div className="text-center space-y-8 flex flex-col items-center justify-center min-h-[400px]">
                                <h2 className="text-2xl text-yellow-400 blink-text">전투 데이터 분석 중...</h2>
                                <div className="pixel-box w-3/4">
                                    <p className="text-sm typewriter">
                                        행동 패턴 스캔 중...<br/>
                                        분노 게이지 측정 중...<br/>
                                        무기(논리/목소리) 분석 중...<br/>
                                        삐빅- 몬스터 식별 완료!
                                    </p>
                                </div>
                            </div>
                        )}

                        {/* 결과 화면 */}
                        {step === 'result' && resultData[finalType] && (
                            <div className="w-full space-y-6 pb-10">
                                <div className="text-center">
                                    <span className="text-gray-400 text-sm block mb-2">당신이 각성한 몬스터는...</span>
                                    <h2 className="text-2xl text-yellow-400 mb-2">{resultData[finalType].title}</h2>
                                    <h1 className="text-3xl text-red-500 font-bold mb-4">{resultData[finalType].name}</h1>
                                    <span className="bg-white text-black px-2 py-1 text-xs">TYPE : {finalType}</span>
                                </div>

                                <div className={`pixel-box ${resultData[finalType].isBoss ? 'pixel-box-boss' : ''} space-y-4`}>
                                    <div className="bg-black p-3 border border-gray-700">
                                        <p className="text-yellow-300 text-sm">" {resultData[finalType].quote} "</p>
                                    </div>
                                    <p className="text-sm leading-relaxed">
                                        {resultData[finalType].desc}
                                    </p>
                                    
                                    {resultData[finalType].solution && (
                                        <div className="mt-4 pt-4 border-t border-gray-600">
                                            <h3 className="text-green-400 text-sm mb-2">🛡️ 공략법 (대처 매뉴얼)</h3>
                                            <p className="text-xs text-gray-300 leading-relaxed">
                                                {resultData[finalType].solution}
                                            </p>
                                        </div>
                                    )}
                                </div>

                                <div className="flex flex-col space-y-3 pt-6">
                                    <button 
                                        onClick={openEncyclopedia}
                                        className="btn-pixel w-full py-3 bg-blue-600 border-blue-200 text-white hover:bg-white hover:text-blue-600"
                                    >
                                        &gt; 전체 몬스터 도감 보기
                                    </button>
                                    <button 
                                        onClick={restart}
                                        className="btn-pixel w-full py-3 hover:bg-white hover:text-black"
                                    >
                                        &gt; 다시 테스트하기
                                    </button>
                                </div>
                            </div>
                        )}

                        {/* 몬스터 도감 (전체 결과) 화면 */}
                        {step === 'encyclopedia' && (
                            <div className="w-full pb-10">
                                <div className="sticky top-0 bg-[#1a1a1a] pt-4 pb-4 z-10 border-b-2 border-white mb-6 text-center flex flex-col gap-3">
                                    <h1 className="text-2xl text-yellow-400">📖 진상 몬스터 도감</h1>
                                    <p className="text-xs text-gray-400">총 16종의 몬스터가 발견되었습니다.</p>
                                    <button 
                                        onClick={backToResult}
                                        className="btn-pixel py-2 px-4 text-xs mt-2 self-center bg-gray-800 hover:bg-white hover:text-black"
                                    >
                                        &lt; 내 결과로 돌아가기
                                    </button>
                                </div>

                                {/* 5대 레전드 보스 섹션 */}
                                <h2 className="text-xl text-red-500 mb-4 px-2">🔥 전설의 네임드 보스 (5종)</h2>
                                <div className="space-y-4 mb-10 px-2">
                                    {Object.keys(resultData).filter(key => resultData[key].isBoss).map(key => (
                                        <div key={key} className={`pixel-box pixel-box-boss relative ${finalType === key ? 'border-yellow-400 shadow-[4px_4px_0px_#ccb800]' : ''}`}>
                                            {finalType === key && <span className="absolute -top-3 -right-3 bg-yellow-400 text-black px-2 py-1 text-xs animate-bounce">MY TYPE!</span>}
                                            <div className="flex justify-between items-end mb-2">
                                                <h3 className="text-lg text-white font-bold">{resultData[key].name}</h3>
                                                <span className="text-xs bg-red-600 px-1">{key}</span>
                                            </div>
                                            <p className="text-xs text-yellow-300 mb-2">{resultData[key].title}</p>
                                            <p className="text-xs text-gray-300 leading-relaxed">"{resultData[key].quote}"</p>
                                        </div>
                                    ))}
                                </div>

                                {/* 11대 일반 몬스터 섹션 */}
                                <h2 className="text-xl text-green-400 mb-4 px-2">👾 일반 몬스터 (11종)</h2>
                                <div className="grid grid-cols-1 gap-4 px-2">
                                    {Object.keys(resultData).filter(key => !resultData[key].isBoss).map(key => (
                                        <div key={key} className={`pixel-box p-3 bg-gray-900 relative ${finalType === key ? 'border-yellow-400 shadow-[4px_4px_0px_#ccb800]' : 'border-gray-500 shadow-[4px_4px_0px_#444]'}`}>
                                            {finalType === key && <span className="absolute -top-3 -right-3 bg-yellow-400 text-black px-2 py-1 text-xs animate-bounce">MY TYPE!</span>}
                                            <div className="flex justify-between items-center mb-1">
                                                <h3 className="text-sm text-white font-bold">{resultData[key].name}</h3>
                                                <span className="text-[10px] bg-gray-700 px-1 text-white">{key}</span>
                                            </div>
                                            <p className="text-xs text-gray-400 leading-relaxed">"{resultData[key].quote}"</p>
                                        </div>
                                    ))}
                                </div>
                                
                                <div className="mt-8 px-2">
                                    <button 
                                        onClick={restart}
                                        className="btn-pixel w-full py-4 text-lg bg-red-600 border-white hover:bg-white hover:text-red-600"
                                    >
                                        &gt; 메인 화면으로 (다시하기)
                                    </button>
                                </div>
                            </div>
                        )}
                    </div>
                </div>
            );
        };

        const root = ReactDOM.createRoot(document.getElementById('root'));
        root.render(<App />);
    </script>
